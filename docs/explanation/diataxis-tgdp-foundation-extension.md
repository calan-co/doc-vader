Diátaxis should be used as the conceptual foundation for documentation and backlog organization. It provides the structure and intent-based categorization (tutorial, how-to, explanation, reference).

The Good Docs Project (TGDP) templates should be used as extensions to implement each Diátaxis category, providing detailed, standardized content and best practices.

This approach ensures clarity, usability, and quality across all documentation and work tracking artifacts.
