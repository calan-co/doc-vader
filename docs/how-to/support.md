## Getting Help

- Check [[faq]] and [[Troubleshooting]]
- Open a GitHub Issue for bugs or feature requests
- Contact maintainers for security concerns
- For urgent issues, email the project owner (see repository contact)

## Escalation

- If your issue is not resolved within 3 business days, escalate via email or project chat
- For security vulnerabilities, use private channels for disclosure
