This guide explains how to use the Release Notes template from The Good Docs Project.

## Purpose

The Release Notes template is for documenting new features, bug fixes, and changes in each release.

## How to Use

- **Version Table**: List versions, dates, and highlights.
- **Change Log**: Summarize changes for each release.
- **Upgrade Notes**: Provide instructions for upgrading if needed.

## Best Practices

- Be clear and chronological.
- Use tables for clarity.

## Additional Resources

See [The Good Docs Project Release Notes Template](https://thegooddocsproject.dev/templates/release-notes/).
