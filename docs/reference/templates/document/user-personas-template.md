This document defines the structure and required fields for user personas.

## Template Structure

- Name or type
- Dimension (description)
- Goals
- Needs
- Pain points
- Role
- Experience level
- Technical expertise
- Use case
- Thinking pattern

See the [[how-to/process-user-personas|How-to Guide]] for instructions on using this template.
