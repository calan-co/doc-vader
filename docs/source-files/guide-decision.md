This guide explains how to use the Decision template from The Good Docs Project.

## Purpose

The Decision template is for documenting architectural or technical decisions, including context, options, and rationale.

## How to Use

- **Context**: Describe the problem or situation.
- **Decision Drivers**: List factors influencing the decision.
- **Options**: Summarize considered options.
- **Decision Outcome**: State the chosen option and rationale.
- **Consequences**: Note any follow-up actions or implications.

## Best Practices

- Be objective and concise.
- Use tables or lists for clarity.
