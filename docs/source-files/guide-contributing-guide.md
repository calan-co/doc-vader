This guide explains how to use the Contributing template from The Good Docs Project.

## Purpose

The Contributing template helps you document how users and developers can contribute to your project.

## How to Use

- **Introduction**: Explain the value of contributions.
- **How to Contribute**: List steps for submitting issues, pull requests, or documentation.
- **Code of Conduct**: Reference or summarize your project's code of conduct.
- **Review Process**: Describe how contributions are reviewed and accepted.

## Best Practices

- Be welcoming and clear about expectations.
- Link to additional resources as needed.

## Additional Resources

See [The Good Docs Project Contributing Template](https://thegooddocsproject.dev/templates/contributing/).
