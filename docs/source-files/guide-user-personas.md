This guide explains how to use the User Personas template from The Good Docs Project.

## Purpose

The User Personas template is for documenting archetypal users, their needs, and behaviors.

## How to Use

- **Persona Overview**: Describe the persona's background and goals.
- **Attributes**: List key characteristics and motivations.
- **Scenarios**: Provide example situations or user stories.

## Best Practices

- Use real data where possible.
- Update personas as your understanding evolves.

## Additional Resources

See [The Good Docs Project User Personas Template](https://thegooddocsproject.dev/templates/user-personas/).
