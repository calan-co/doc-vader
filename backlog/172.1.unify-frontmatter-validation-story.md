## Statement

As a maintainer, I want frontmatter validation to run inside remark so that schema errors are reported consistently with other rules.

## Context

Legacy validators run outside unified, causing drift and different error formats.

## Actors

- Primary: maintainers and contributors

## Goals

- Schema validation parity and consistent messages

## Preconditions

- [ ] Ajv configured and schema directory known

## Steps

1. Implement plugin with Ajv cache (keyed by path + mtime)
2. Add STRICT_FRONTMATTER toggle logic
3. Replace CLI usage and capture snapshots for parity

## Outcomes

- Single-pass schema checks in remark

## Acceptance Criteria

- [ ] Plugin reports missing/invalid fields per schema
- [ ] Parity snapshots reviewed and deltas documented
