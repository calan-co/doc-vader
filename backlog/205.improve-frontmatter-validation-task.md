## Description

Ensure all markdown documentation files start with a single, properly fenced YAML frontmatter block at the very top, with all required fields present and correctly formatted. Remove any duplicate or misplaced metadata blocks.

## Acceptance Criteria

- All markdown documentation files start with a single, properly fenced YAML frontmatter block at the very top.
- All required fields are present and correctly formatted.
- No duplicate or misplaced metadata blocks remain.
- Linting and schema validation pass without errors.
