## Description

Systematically review all files in `staging/scripts/` and `staging/schemas/` to classify each as:

- **Core**: Migrate to TypeScript ESM
- **Deprecated**: Archive with notice
- **Compatibility**: Keep as shim/example

## Acceptance Criteria

- [ ] Inventory spreadsheet or markdown table with recommendations
- [ ] Dependencies and overlap with Epic 170 identified
- [ ] Migration priorities assigned
