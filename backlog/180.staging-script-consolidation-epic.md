## Description

Review all scripts and schemas in `doc-vader/staging/` to determine which should be migrated to TypeScript ESM as core functionality, which should be deprecated, and which should remain as compatibility shims or examples.

## Context

The `staging/` folder contains CommonJS scripts that conflict with the parent `doc-vader` package's `"type": "module"` declaration. Many of these scripts duplicate functionality that should be part of the core TypeScript codebase, while others may be deprecated or superseded by the unified/remark-lint pipeline (Epic 170).

## Acceptance Criteria

- [ ] All staging scripts audited with migration/deprecation/retention recommendations
- [ ] Core linting and validation logic migrated to TypeScript ESM under `lib/` or `cli/`
- [ ] Obsolete scripts archived with clear deprecation notices
- [ ] Package.json scripts updated to reference core implementations
- [ ] Documentation reflects new architecture and migration path
