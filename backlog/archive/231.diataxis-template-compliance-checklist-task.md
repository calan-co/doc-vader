## Summary

Create a concrete Diataxis placement and template compliance checklist to support Epic 170 Track B implementation and testing.

## Background

The story for Diataxis template enforcement identifies placement and section requirements, but the repository lacks one explicit checklist that implementers and reviewers can use as a shared contract.

## Goals

- Document expected folder placement by document intent
- Identify required headings or sections by Diataxis type
- Provide a checklist consumable by plugin implementation and documentation review

## Deliverables

- Placement matrix for guide, how-to, reference, and explanation content
- Template compliance checklist with required sections by type
- Examples of compliant and non-compliant structures for tests and docs

## Tasks

1. Define the folder-placement rules for each Diataxis type
2. Enumerate the required section checks for each supported template
3. Package the rules into a checklist usable by implementation and review

## Acceptance Criteria

- [ ] Folder-placement rules are documented for supported Diataxis types
- [ ] Template checklist identifies required sections for each supported type
- [ ] Checklist can be referenced by Epic 170 Track B implementation and tests
