## Statement

As a maintainer, I want a comprehensive inventory of all staging scripts and schemas so that I can prioritize migration and deprecation work.

## Context

The `staging/` folder has accumulated scripts over time. We need to assess each for relevance, duplication with Epic 170, and migration priority.

## Actors

- Primary: maintainers
- Secondary: contributors

## Goals

Clear categorization and migration plan for all staging assets.

## Preconditions

- [x] Access to staging folder and git history

## Steps

1. List all files in `staging/scripts/` and `staging/schemas/`
2. For each script, determine purpose and dependencies
3. Categorize as Core, Deprecated, or Compatibility
4. Document findings in a table

## Outcomes

Inventory table with recommendations for each staging asset.
