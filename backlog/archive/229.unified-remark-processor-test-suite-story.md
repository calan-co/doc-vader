## Statement

As a maintainer, I want a focused test and benchmark suite for the unified remark processor so that Epic 170 Phase 1 has an executable exit gate.

## Context

The repository has a processor implementation surface and several plugin tracks, but Phase 1 lacks a single regression suite that validates processor composition, CLI wiring, and basic performance expectations.

## Goals

- Add regression tests for processor assembly and execution
- Record startup and representative linting baselines
- Make the Phase 1 exit criteria executable in CI

## Deliverables

- Processor-focused unit and integration tests
- Benchmark notes or fixtures for startup and representative corpus runs
- Documented Phase 1 validation gate for Epic 170

## Tasks

1. Identify the current unified processor surface and CLI entrypoints
2. Add focused tests for plugin composition and processor execution
3. Capture baseline metrics for startup and representative lint runs
4. Document the required pass conditions for Phase 1 completion

## Acceptance Criteria

- [ ] Unified processor tests cover processor composition and CLI integration
- [ ] Baseline measurements are recorded for startup and representative lint runs
- [ ] Epic 170 Phase 1 has a documented executable validation gate
