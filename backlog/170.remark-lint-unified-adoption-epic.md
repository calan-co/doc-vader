## Description

This epic delivers a single, extensible linting architecture based on unified/remark-lint. It replaces bespoke validators with remark plugins for schema, template/Diátaxis, cross-references, naming, backlog semantics, lifecycle rules, and policies.

## Scope (Shared-Engine MVP Plan)

- Shared linting architecture baseline for `doc-vader` and downstream consumers.
- Trunk integration points for schema validation, docs-lint orchestration, and profile-ready governance.
- Foundation work consumed by both the hygiene lane and consumer stabilization lane in the MVP plan.

## Acceptance Criteria

- [ ] `.remarkrc.mts` defines the canonical pipeline and runs locally and in CI
- [ ] Frontmatter schema validation via Ajv is executed inside remark
- [ ] Diátaxis placement and template compliance enforced with remark rules
- [ ] Cross-file checks (crossref, naming, backlog, lifecycle) use a shared registry
- [ ] Optional policies and non-mutating suggestions available
- [ ] Legacy scripts deprecated behind a one-release fallback
- [ ] Backlog hygiene cleanup lane is fully operational and documented
- [ ] `backlog validate` supports `--fail-on`, `--profile`, `--format json`
