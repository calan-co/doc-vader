## Statement

As a maintainer, I want the unified pipeline to run in CI/dev flows and legacy scripts to be deprecated with a clear migration path.

## Context

Multiple entrypoints and modes confuse contributors and slow adoption.

## Actors

- Primary: maintainers and contributors

## Goals

- Unified pipeline as primary entrypoint
- Perf/full modes documented and selectable
- Legacy fallback maintained for one release, then removed

## Preconditions

- [ ] Unified pipeline implemented and tested

## Steps

1. Update npm scripts to use remark
2. Document perf/full modes and env flags
3. Maintain legacy fallback for one release; plan removal

## Outcomes

- Seamless developer experience; clear migration path

## Acceptance Criteria

- [ ] Unified pipeline runs in CI/dev
- [ ] Legacy fallback removed after one release
