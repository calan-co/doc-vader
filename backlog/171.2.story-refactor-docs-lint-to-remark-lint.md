## Statement

As a maintainer, I want to refactor the docs-lint.sh script to use remark-lint and unified plugins so that documentation linting is standardized, extensible, and easier to maintain.

## Context

Current linting uses markdownlint-cli2 and custom shell/node scripts. Unified/remark-lint offers a more flexible, plugin-based approach and is already used for core pipeline.

## Goals

- Replace markdownlint-cli2 with remark-lint and unified plugins
- Use existing plugins for style, crossref, anchor, frontmatter, template, etc.
- Create new plugins if needed to match current linting rules
- Ensure all current linting checks are covered
- Update docs-lint.sh to orchestrate remark-lint pipeline

## Acceptance Criteria

- [ ] docs-lint.sh uses remark-lint and unified plugins for all checks
- [ ] All current linting rules are covered by plugins
- [ ] New plugins created for any missing rules
- [ ] Documentation updated to reflect new linting approach
- [ ] Tests cover happy path and error modes for new plugins
