## Problem

The `protect-long-lived-branches` ruleset on consumer repos (e.g. `templjs/templ.js`) requires a PR for
all pushes to long-lived branches.  The backlog sweep workflow needs to commit archival changes directly
to `staging` without opening a PR for every run.

The short-term fix (story 227 short-term: see Notes) adds `github-actions[bot]` (app ID 15368) as a
bypass actor.  This is overly broad — it grants any workflow in the repo the same bypass privilege.

## Goal

Register a `doc-vader` GitHub App and use its identity as the narrow bypass actor, so only workflows
that authenticate as `doc-vader[bot]` can push directly to protected branches.

## Proposed Steps

1. Create a GitHub App named `doc-vader` under the `calan-co` org (or a shared org).
2. Grant the app `contents: write` and `pull_requests: write` repository permissions.
3. Store app credentials (App ID + private key) as repository/org secrets in consumer repos.
4. Update the sweep workflow to generate a short-lived installation token via the app credentials
   (`actions/create-github-app-token`) and use that token for git operations and gh CLI calls.
5. In consumer repos, replace the `github-actions[bot]` bypass actor entry with the `doc-vader[bot]`
   app entry (actor_type: `Integration`, actor_id: doc-vader app ID).
6. Remove the `github-actions[bot]` bypass entry added as the short-term fix.

## Acceptance Criteria

- [ ] `doc-vader` GitHub App exists and is installed on at least `templjs/templ.js`.
- [ ] Sweep workflow authenticates as `doc-vader[bot]` when committing and pushing.
- [ ] `doc-vader[bot]` is the bypass actor on `protect-long-lived-branches`; `github-actions[bot]` entry removed.
- [ ] No other workflow in consumer repos gains elevated push access as a side-effect.
- [ ] App credentials are stored as secrets; private key is not committed to any repo.
- [ ] Documented: how consumer repo owners install the app and rotate the private key.

## Non-Goals

- Changing the sweep workflow logic beyond authentication.
- Creating a full GitHub App marketplace listing.
