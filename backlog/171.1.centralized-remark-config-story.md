## Statement

As a contributor, I want a single, canonical remark configuration and a programmatic processor so that all rules run consistently in local dev, CI, and tests.

## Context

Existing scripts compose processors ad hoc; options and exports differ across plugins.

## Actors

- Primary: maintainers and contributors

## Goals

- Unified config and export shapes
- Minimal cognitive overhead to run linting in any environment

## Preconditions

- [ ] Existing plugins identified and reachable under `lib/plugins`

## Steps

1. Add `.remarkrc.mjs` with Layer 0–2
2. Implement `createTiabProcessor()` factory
3. Normalize existing plugins and add zod option schemas
4. Write unit tests and smoke integration

## Outcomes

- Single source of truth for rule composition

## Acceptance Criteria

- [ ] `.remarkrc.mjs` and factory run in local dev and CI
- [ ] Plugins expose consistent signatures and validated options
- [ ] Tests cover happy path + 1–2 error modes per plugin
