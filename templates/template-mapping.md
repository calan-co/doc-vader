| Template File                                                                     | Intent / Purpose                                         | Diátaxis Category |
| --------------------------------------------------------------------------------- | -------------------------------------------------------- | ----------------- |
| [tutorial.md](https://www.thegooddocsproject.dev/template/tutorial)               | Teach users a skill or process through hands-on learning | Tutorial          |
| [how-to.md](https://www.thegooddocsproject.dev/template/how-to)                   | Guide users through steps to solve a specific problem    | How-to            |
| [reference.md](https://www.thegooddocsproject.dev/template/reference)             | Provide structured, concise information for lookup       | Reference         |
| [concept.md](https://www.thegooddocsproject.dev/template/concept)                 | Explain a concept, context, or background information    | Explanation       |
| [troubleshooting.md](https://www.thegooddocsproject.dev/template/troubleshooting) | Help users resolve specific problems or errors           | How-to            |
| [readme.md](https://www.thegooddocsproject.dev/template/readme)                   | Introduce the project, its purpose, and usage            | Reference         |

## Notes

- All templates include a `source` property for provenance.
- Diátaxis category is assigned per project rules and decision trees.
- Troubleshooting guides are classified as How-to per Diátaxis.
- README is classified as Reference for project onboarding and lookup.
