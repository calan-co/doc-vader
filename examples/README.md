# Examples

This directory provides sample agent and workflow assets for doc-vader.

## Structure

- `agent.example.*` and `workflow.example.*`: example agent and workflow definitions
- `agents/` and `workflows/`: additional example files
- `api-client.md`: API client usage samples
- `system-tools-sample-invocations.md`: system tool invocation samples

Use these files as templates when building your own agents and workflows.
